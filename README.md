# Zurab Vashakidze — Academic Website

Source files for the personal academic website published from this repository with GitHub Pages.

## Site structure

- `index.html` — academic profile content and structured metadata
- `styles.css` — responsive styling
- `assets/favicon.svg` — site icon

## Updating the site

Edit `index.html` for biography, publications, teaching, and profile links. Edit `styles.css` for design changes. Changes committed to the Pages publishing branch can be deployed automatically by GitHub Pages.
